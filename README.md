# Monthly Challenge

A Spring Boot REST API project for managing monthly coding challenges.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Gradle
- REST API
- IntelliJ IDEA
- Postman

## Features

- Create a new challenge
- View all challenges
- View a challenge by ID
- Update a challenge
- Delete a challenge
- Store challenge data in MySQL
- RESTful API architecture
